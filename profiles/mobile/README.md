# {{App Name}}

Mobile application repository using the `{{platform_profile}}` Cortext profile.

This template keeps the Cortext split between normative specifications,
machine-readable contracts, developer documentation, and executable tests while
adding the lifecycle, security, privacy, accessibility, and release concerns that
mobile applications require.

## Template origin

This repository was generated from the Cortext mobile profile. Its template version
and selected platform are recorded in `.cortext-template.json`.

The template generator creates an honest repository boundary and platform layout. It does
not synthesize an Xcode project, Gradle project, or cross-platform framework
configuration. Create those files with official platform tooling.

See [specs/repo-standard.md](specs/repo-standard.md) for the complete standard.
